# ADR-002: Flagship application (LeadOps) lives outside the kernel

**Status:** Accepted (flagship changed to the generalist swarm in PRD v3; the kernel-purity rule this ADR establishes is unchanged and LeadOps remains as second-domain proof) · **Date:** 2026-08-24

## Context
A runtime without a real workload is a benchmark in search of a reason. But business
logic inside the kernel would make it a framework.

## Decision
`src/swarmd/` stays pure infrastructure. The LeadOps sales pipeline (INGEST → ENRICH →
DEDUPE → SCORE → DRAFT → QA → REVIEW) lives in `examples/leadops/` as a first-class,
production-shaped embedder — proving the kernel by using it the way a real user would.

## Consequences
- Every kernel feature must be exercised through LeadOps before release.
- LeadOps doubles as reference documentation for embedders.
